# EventsHere

EventsHere is a web application designed to manage college-related events with dedicated interfaces for administrators and students.

## 🚀 Tech Stack
- **Frontend**: EJS, Bootstrap
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL

## 🌟 Features
- **Administrator Interface**: Manage and monitor events efficiently.
- **Student Interface**: View and participate in events seamlessly.
- **Dynamic Webpages**: Built with EJS for interactive and data-driven UI.
- **Responsive Design**: Utilized Bootstrap for optimal viewing on all devices.
- **Data Management**: Securely stores and retrieves event details in PostgreSQL.
